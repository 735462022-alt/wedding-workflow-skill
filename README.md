# 婚礼筹备超省心

面向婚礼主持人和现场执行人员的通用工作流：整理资料、制作流程、准备物品、生成当天执行表、撰写主持词。无固定品牌、无 Logo，不附带真实新人资料。

## 六个模块

| 模块 | 输出 |
| --- | --- |
| 新人信息确认 | 已确认事实、来源冲突和待确认项 |
| 婚礼时间流程 | 新娘与新郎早晨双线，接亲后共同流程 |
| 婚礼仪式流程 | 按本场实际顺序排列的仪式环节 |
| 婚礼物品筹备 | 女方、男方分栏的物品与数量清单 |
| 婚礼当天执行表 | 六列可编辑 Excel，不含电话列、音乐清单或勾选框 |
| 个性化主持词 | 基于真实故事的独立分环节主持稿 |

可以只做一个模块；不会因为调用本 Skill 就自动生成全套文件。

## Codex 使用

本仓库是一个独立 Skill 文件夹，不是插件商店上架包。

显示名称为“婚礼筹备超省心”；英文技术标识仍为 `wedding-workflow-skill`，用于文件夹名称和 `$wedding-workflow-skill` 调用。

将仓库下载或克隆为 `wedding-workflow-skill` 文件夹，放到下列任一位置：

- 项目内：`.agents/skills/wedding-workflow-skill/`
- 个人目录：`~/.agents/skills/wedding-workflow-skill/`

确保该目录内直接包含 `SKILL.md`。安装位置与调用方法以 [OpenAI 官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills) 为准。

调用示例：

```text
使用 $wedding-workflow-skill，根据我提供的本场婚礼资料，先整理已确认信息和待确认项，然后只制作当天执行 Excel。不要做其他模块。
```

资料不足时标记“待确认”，不从示例中补入姓名、时间或环节。文档、图片和 Excel 文件的实际生成能力取决于运行环境；没有相应工具时，会明确提供文字表格或制作简报，不伪造下载文件。
