# 婚礼筹备超省心 · 豆包对话适配

本文件提供可复制的工作流提示词，适用于普通豆包对话。它不是原生 `SKILL.md` 安装教程，不承诺豆包会自动读取本仓库的参考文件、加载模板、运行脚本或生成可下载文件。

在新对话中粘贴下面的提示词，再提供本场资料及所需交付物。每换一场婚礼，重新提供本场资料；不要依靠上一场的记忆补全。按当前界面实际支持的方式提交文字或附件，不能读取的附件改为粘贴相关内容。

## 可复制提示词

```text
请协助我整理一场婚礼。只使用本次提供的聊天、图片、文档或表格，不沿用其他婚礼的人名、日期、地点、人物关系、故事和习俗。

先整理已确认事实、来源冲突和待确认项。缺失统一写“待确认”；保留不同来源的冲突，不猜测时间、数量、称谓、路线或负责人。用户指定底稿时，以该底稿和本次明确更正为准。能够继续的部分先做，关键分歧集中询问。

我会从以下六个模块中选择需要的交付物；只有我要求整套工作包时才制作全部六项：
1. 新人信息确认：基础信息、关键人物、冲突与待确认问题。
2. 婚礼时间海报：新娘、新郎早晨双线并行，在接亲或会合节点汇流，之后采用共同流程。
3. 婚礼仪式海报：本场正式仪式的顺序与必要说明；没有具体钟点时不编造分钟数。
4. 物品筹备清单：默认女方、男方分栏，各栏按用途分类，只列物品与数量，可有勾选框。不混入人员职责、联系人或流程安排。未明确数量或由哪方准备时写“待确认”；补充建议与确认清单分开。
5. 婚礼当天执行表：只含当天执行，六列依次为“时间、地点/路线、执行事项、动作与完成标准、关键人员、物品”。原始备注与待确认信息应保留，不增加未确认的职责、口令或完成条件。删除婚前岗位与物资确认整组，不含音乐、电话、负责人联络栏、LOGO、勾选框或勾选提示。新人信息放第一行；顶部日期、场地、仪式时间等信息分为上下对齐的三组。正文宽松、网格实线清楚；能设置表格冻结时只冻结顶部信息与表头，不冻结首列。
6. 独立婚礼主持稿：优先使用我指定的文风。只写真实提供的经历；旧稿仅参考风格。提供样本时统计同类口播正文的大致篇幅，没有样本时不强制固定字数。可采用温暖、真实、克制的表达，不套用旧故事，不默认加入个人品牌或口号。

本工作流没有默认品牌或LOGO。视觉、纸张、字体、行高和条目数按本场需要调整。不要将婚礼资料上传、分享或公开发布，除非我明确要求。

请先确认当前对话实际具备哪些文件、图片或设计能力。能生成文件时提供真实存在的成品并核对姓名、时间、数量、顺序和版面；不能生成Excel或文档时说明限制，提供完整可复制表格或正文；不能生成海报时提供准确文案和图像设计简报。不要声称已运行脚本、自动加载仓库资源或完成无法执行的导出，不编造下载链接。

本场资料：
[在这里粘贴资料，或说明本次已提供的附件]

本次需要的交付物：
[填写模块及期望格式]

本次指定底稿、风格或其他要求：
[填写；未确定的内容写待确认]
```

## 使用结果的检查

先核对人物、时间和环节，再确认排版。后续只修改局部时，明确指出当前底稿及修改范围。豆包若只返回文本，那就是文本结果；需要 Excel、文档或海报成品时，可将核对过的内容交给具备相应能力的工具继续制作。
