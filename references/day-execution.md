# 婚礼当天 Excel 执行表

目标是在现场快速查到何时、何地、做什么、涉及谁和需要什么。只放当天执行事项。

## 内容边界

- 包含当天准备、人员到场、用品交接或清点、接亲、换装、拍摄、迎宾、仪式和其他本场明确安排。
- 不含婚前岗位招募、婚前采购、婚前岗位与物资确认整组。
- 默认六列中不放音乐、电话、负责人联络栏，不放个人品牌或 LOGO，不在事项前加勾选框，也不保留“完成后打勾”等说明。
- 筹备清单可以另含婚前准备和勾选框；不要因为执行表的要求删除其他交付物中的这些内容。
- 用户明确指定底稿时，从该底稿提取当天记录。压缩列数时保留原有当天动作、备注、人员、物品与不确定性，不借机增加职责或口令。

## 六列

| 列 | 内容 |
| --- | --- |
| 时间 | 原始钟点、时间区间或已知顺序；未知写待确认 |
| 地点/路线 | 本场场地、房间或明确路线；未知部分标待确认 |
| 执行事项 | 简短动作标题；有顺序的环节可用序号 |
| 动作与完成标准 | 来源明确的动作、完成条件及影响执行的备注；不虚构验收标准 |
| 关键人员 | 该环节涉及的已知人物或角色；未知姓名、身份仍待确认 |
| 物品 | 该环节使用的物品及已知数量；未知部分待确认 |

“关键人员”不等于任命负责人。来源只有动作名称时，可以简短保留，不为填满单元格发明站位、手势、主持提示或递送安排。

新娘、新郎早晨分别成段，标明并行；在接亲或会合处进入共同流程。阶段总时间只出现于对应组，不给组内每项编造分钟数。合并的时间、地点单元格必须准确覆盖其流程，不能吞掉子项。

## 顶部与表格排版

第一行优先展示新人姓名或新人信息；下一行放“婚礼当天执行表”。其下两行采用同一组三块信息区，边界和文字对齐：

- 第一组：婚礼日期；宴席类型。
- 第二组：酒店或场地；开席时间。
- 第三组：仪式开始；浅黄色为待确认信息的说明。

六列工作表可将三块分别安排在 A:B、C:D、E:F；上下两行使用相同合并范围。标签与值使用一致格式，统一对齐方式，避免标题、酒店和时间零散漂浮。底层列宽不同，无须强求三块等宽。

正文要求：

- 六列表头清楚，列间与行间有可见的灰色实线边框。阶段标题可以全宽合并；合并单元格不应被内部线条穿过。
- 留足列宽、行高和阶段留白。长句自然换行，不把姓名、数字与量词、词语机械拆开；正文不截断、不溢出。
- 可用浅米色和低饱和强调色建立层次，待确认单元格用浅黄提示，不依赖颜色单独传达状态。
- 只冻结顶部信息与表头行，不冻结首列或其他正文列，避免竖向冻结线穿过合并的新人标题。

可从 [空白模板](../assets/day-execution-template.xlsx) 开始，按本场内容调整行数与分组。模板占位符不是本场事实。

不固定某场的条目数、钟点、纸张大小、字号或行高。根据实际内容选择可读的屏幕与打印尺寸；打印通常设为一页宽、高度自动分页，并重复必要表头，避免为了塞进一页而把全文缩得过小。

## 核验

核对正文条目是否覆盖底稿中全部应保留的当天安排，改列后原备注、人员与物品是否错位。确认音乐和联络字段已按本表范围移除，未误删其他事实。

检查新人姓名位于首行、顶部块边界对齐、六列网格清楚、无勾选提示、无 LOGO、无首列冻结，并查看实际渲染或打印预览中的截断、分页和合并格。

能够生成 Excel 时交付可编辑 `.xlsx`；不能生成时，说明限制并提供同样六列的可复制表格，不编造下载链接。
